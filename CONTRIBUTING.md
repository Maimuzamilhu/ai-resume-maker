# Contributing to Resume AI Maker

Thank you for your interest in contributing to **Resume AI Maker**! 

Whether you want to submit a new resume layout, recommend features, or report a bug, we value your feedback.

---

## How to Contribute

### 1. Submit a Resume Template
If you have a professional, ATS-friendly resume layout or style that you want supported in the builder, we would love to integrate it!
* Please email your template file (PDF, DOCX, or HTML format) to **[muzzamilkhalidai@gmail.com](mailto:muzzamilkhalidai@gmail.com)**.
* Include a brief description of the target industry (e.g., tech, finance, creative) and any specific design formatting guidelines.

### 2. Feature Recommendations & Bug Reports
Since the project is under active development, your feedback is crucial in tracking down glitches, printing issues, and improving usability.
* To suggest new features, report bugs, or recommend options/improvements, feel free to write to us directly at **[muzzamilkhalidai@gmail.com](mailto:muzzamilkhalidai@gmail.com)**.

---

## Coding and Extensions

This repository serves as a **promotional showcase** of the application design, user journey, and architecture. The full backend, database schemas, and cloud-printing source code are kept in a separate private repository. 

If you are interested in self-hosting or custom enterprise modifications, please get in touch via email.
